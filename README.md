# 🌸 祺祺的生活工作台

一个完全在**手机浏览器里运行**的个人生活管理平台。左右分栏布局，10 大功能模块，所有数据都保存在手机本地（localStorage），支持导出/导入备份。

> 这是一个**纯静态网页**（无需后端、无需数据库），部署到任意静态托管就能用，手机浏览器打开后还能**添加到主屏幕当成 App 用**。

---

## 📦 怎么部署（任选一种，几分钟搞定）

### 方式一：GitHub Pages（免费、最省事）
1. 新建一个 GitHub 仓库（Public）。
2. 把 `index.html`、`app.js`、`data-books.js`、`data-movies.js`、`manifest.json`、`sw.js`、`icon192.png`、`icon512.png` 这 8 个文件上传到仓库根目录。
3. 仓库 `Settings` → `Pages` → Source 选 `main` 分支、`/ (root)` → 保存。
4. 等 1–2 分钟，访问 `https://你的用户名.github.io/仓库名/` 即可。

### 方式二：腾讯云 COS 静态网站（国内访问快）
1. 开通对象存储 COS，创建一个存储桶，权限设为**公有读私有写**。
2. 把 8 个文件上传进去。
3. 存储桶 → 基础配置 → 开启「静态网站」，记下访问域名。
4. 手机浏览器打开该域名即可。

### 方式三：Vercel / Netlify（拖拽上传）
1. 打开 vercel.com 或 netlify.com，登录。
2. 把 8 个文件拖进部署页面（或直接拖这个 zip）。
3. 得到公网链接，打开即用。

> ⚠️ **注意**：请让 `index.html` 位于网站的**根路径**（不要放在子目录里，除非你同步改了 manifest 和 sw.js 里的相对路径）。

## 📱 手机上一打开就像 App 一样用

部署好后，在手机浏览器打开链接：

- **iPhone**：点底部 **分享** 按钮（方框箭头）→ **添加到主屏幕**。桌面会出现「祺祺生活台」图标，点开**全屏、无地址栏**运行，像原生 App。
- **安卓（Chrome）**：点右上角 **⋮** → **添加到主屏幕 / 安装应用**。桌面出现图标，全屏运行。

首次打开会有引导提示。数据都存在手机本地，离线也能用。

## 🧩 功能模块

| 模块 | 说明 |
|------|------|
| 👗 电子衣橱 | 上传衣物/配饰/帽子照片，按分类管理，**按场合（约会/上班/运动…）自动筛选并组合穿搭方案** |
| 🧺 生活消耗 | 记录洗衣液、纸巾等囤货数量与单位的**总库存**，低于警戒线自动提醒补货 |
| ⏰ 赏味期限 | 记录护肤品/美妆/食品保质期，自动**倒计时**（已过期 / 30天内 / 安全） |
| 📚 读书记录 | 豆瓣 Top100 书单排成**冰山地图**，读过的点亮，可左右滑动、放大看完整书名 |
| 🎬 电影记录 | 豆瓣 Top100 片单冰山地图，看过的点亮 |
| 🎡 周末玩耍 | 365 天日历，记录周末计划、实际去哪、和谁玩，出去玩过就**星标** |
| 🎉 节日记录 | 生日/母亲节/春节等，**支持农历和阳历**自动换算与倒计时，默认已生成常用节日 |
| 💪 身体倍棒 | 记录运动（游泳/跑步/羽毛球…）和泡脚 |
| 🗒️ 生活备忘 | 文字 / 图片 / 链接形式随手记 |
| 🧳 行李清单 | 分门别类记录旅行要带的东西，逐项打勾 |

## 💾 数据与备份

- 数据自动保存在手机浏览器本地（localStorage），**不联网也能用**。
- **换手机 / 清缓存前**：在应用左侧底部点「导出数据」下载 JSON → 新手机上装好后点「导入数据」即可完整恢复。

---

## 🛠 技术说明

- 纯前端，无框架依赖，单页应用。
- `app.js`（约 68KB）承载全部逻辑；`data-books.js` / `data-movies.js` 为豆瓣 Top100 书单片单数据。
- `manifest.json` + `sw.js` 让它可以被安装成 PWA、支持离线缓存。
- 祝使用愉快 🌸
